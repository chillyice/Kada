      「长按进入层」= 按住切层键期间该层才生效，松手退回（层内放和弦/序列得一边按住切层键一边凑键，很难按）；「长按锁定层」= 长按一下切到该层并保持生效、再长按一下退出，适合层内放和弦/序列的用法。两者与「长按」互斥。

      文本扩展不参与键位层：它按输入内容匹配，与当前哪一层无关。

      条件不成立时等价于「这条不存在」：落到下一条同触发键的条目，没有就放行原键。

      设置

      命令 / 脚本动作超过「动作超时」会被连子进程一起强制终止并记进消息中心（脚本挂住会永久占住这条触发的执行线程，所以默认 30 秒）。想中止正在跑的动作，去「消息」页点「停止执行」。

      「文本注入」= 文本扩展 / 文本动作把文字送进目标程序的方式。默认「剪贴板粘贴」整段一次到位、中文最稳，但会短暂占用并恢复剪贴板，且被吞粘贴的程序（多数游戏、部分终端）无视；「逐字直发」逐个字符合成按键、不经过剪贴板，专治吞粘贴的目标程序，代价是长文本逐字送、极速输入个别程序可能丢字。

      「输入状态悬浮指示」= 有层或改键修饰键生效时，屏幕底部浮一条小条，显示当前激活层与注入中的修饰键（按住 / 粘滞 / 单次），没有东西生效时自动消失；托盘图标右键悬停也能看到同一句摘要。关掉它就只剩托盘提示。长按锁定层会一直挂着这条指示——这是有意的，锁定层生效期间基础层按键会被遮蔽，「看不见状态」正是最容易被误判成「按键失灵」的时候。

      「快捷键提示框」= 一块常显的速查小窗，把所有已启用的快捷键按层列出来（基础层在最上），随时能瞄一眼「我配过哪些键」。拖动标题栏移动；滚轮调大小、Ctrl+滚轮调透明度（缩小字号能一屏塞下更多条目）；列表太长时 Shift+滚轮 或拖滚动条滚动。位置、大小、透明度都随配置保存，下次启动还在原地。点窗口上的 × 关掉后，回到本页重新勾选、或点托盘图标的「快捷键提示」都能再打开。

      「序列等待」= 键序列（如 F9 J K）按下第一步后，等下一步的最长时间；「和弦等待」= 按下部分和弦成员（如 F&J 的 F）后，等其余成员的最长时间。两者超时都会把被吞掉的键原样补回（序列照常打出来、和弦按单个普通键输入）。默认 1000 毫秒：手慢嫌不够就调大，误触嫌等太久就调小；填 0 = 不限时（一直等到断链 / 成员抬起）。

      键位层

      层让同一按键在不同状态下干不同事：切层键把某层「打开」后，该层的快捷键/改键才生效；归属「基础层」的条目始终生效。切层键 = 改键里设「长按进入层」（按住期间生效）或「长按锁定层」（长按切换、保持生效，层内放和弦/序列用这种）。

      帮助

      变量：提取与引用

      一条快捷键可挂多个动作，按顺序执行。有的动作会把结果「存成变量」，后面的动作用 {变量名} 或 {变量名.字段} 引用。变量只在本次触发内有效，触发结束即清空，不落盘、不跨触发。

      三种提取方式

      动作存成什么怎么引用
      执行命令（填「存为变量」）文本：标准输出 + 退出码{变量名} 得输出全文、{变量名.exit_code} 得退出码
      操作系统 → 获取文件属性文件对象（多个字段）{变量名} 得完整路径、{变量名.字段} 得字段
      应用 → 查询运行状态布尔 true / false{变量名}

      引用语法

      • {变量名}：取整体值——文件属性得完整路径、布尔得 true/false、命令结果得输出全文。
      • {变量名.字段}：取字段。文件属性有 name/path/dir/stem/ext/size/modified/is_dir；命令结果有 exit_code（0=成功）。
      • 未知变量/字段原样保留成 {...}，不会报错、不会中断。

      文件属性字段

      • name 文件名、path 完整路径、dir 所在目录、stem 主名、ext 扩展名、size 大小(字节)、modified 修改时间、is_dir 是否目录。

      实战：把文件复制到「盘符不定」的移动硬盘

      盘符每次插上都不固定（今天 E:、明天 F:），但你知道硬盘卷标。思路：先按卷标查盘符 → 存变量 → 复制动作里用变量拼路径。

      第 1 步：执行命令，按卷标取盘符

      动作类型「执行命令」→ PowerShell，命令：

      (Get-Volume -FileSystemLabel '我的硬盘').DriveLetter

      「存为变量」填 drive。卷标 '我的硬盘' 换成你硬盘的实际卷标（资源管理器里看到的名字）。这句只输出一个字母，如 E。

      第 2 步：复制文件，用变量拼目标路径

      动作类型「操作系统 → 复制」：原始路径 C:\工作\待备份，目标路径 {drive}:\备份\。

      触发后 {drive} 被替换成当天盘符，实际执行 E:\备份\。

      更稳的写法：先确认硬盘在，再复制

      1. 执行命令取盘符 → 存入 drive。
      2. 条件判断：变量字段不等于，变量名 drive、字段留空、值留空（盘符查到才继续）。
      3. 复制 → 目标路径 {drive}:\备份\。

      常见问题

      变量能跨快捷键、或下次触发再用吗？

      不能。变量只在当前这一次触发、按顺序执行的动作里有效，触发结束即清空。

      命令输出带了换行或空格，会影响路径吗？

      不会。「存为变量」会去掉命令输出的首尾空白与换行，只留内容本身。

      取盘符的命令在 CMD 里怎么写？

      可用 wmic logicaldisk where "VolumeName='我的硬盘'" get DeviceID，但输出带表头需自行清洗；推荐用 PowerShell。

      命令的退出码（成功/失败）能拿到吗？

      能。{变量名.exit_code} 得到退出码（0=成功，非 0=失败）；{变量名} 仍是标准输出全文。可配合「条件判断」做「命令失败则…」的分支。

      占位符写错了（变量不存在）会怎样？

      不会报错，{写错的变量名} 会原样保留在字符串里，等于没替换。执行后到「消息」页看结果即可排查。

      变量名有什么限制？

      任意非空字符串即可，别含 {}、.、空白；建议用简单英文/拼音（如 drive、f）。

      合并：只添加导入的条目，现有条目不删不改（触发键/原键/触发词撞车的条目跳过），本机设置不动。
