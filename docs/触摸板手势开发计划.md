**读代码前先记住三条边界**（踩过的坑，别重犯）：

1. 钩子回调里只记点 / 判开关，**不识别、不碰窗口、不做 IO**（超时会被系统摘钩子）；浮层靠轮询快照，不靠回调推送。

## 3. 下一步（按顺序做，别跳）

### 3.1 TP-06 录入界面（✅ V1.92 已落地，真机待验）

**目标**：不手改 JSON 也能配一条触摸板手势，并且**画一笔就能得到方向串 / 模板**。

**实际实现**（V1.92 先做成鼠标操作编辑器里的触发方式下拉；V1.93 改为独立模式，理由见 §4；V1.95 删掉画板、按钮统一叫「录入」）：

- **入口**：模式下拉里独立的「触摸板手势」一项（`section = "touchpads"`），按键框是**触发键下拉（`edit-touchpad-trigger`，只列键盘键）+ 方向串 + 「录入」+「清除模板」**。鼠标操作那边是方向串 + 「录入」（画板），不再有触发方式下拉；触摸板**没有画板**（V1.95 删掉，画板上画的是鼠标轨迹）。
- **「录入」**：壳层 `start_trackpad_record(key)` / `stop_trackpad_record`（`TRACKPAD_RECORD`）开一个**只回填编辑器**的采集会话；松键后壳层用与运行时同一套 `pattern_from_stroke` + `template_from_points` 算好方向串 / 24 点模板，经 `trackpad-recorded` 回填，**不执行动作、不进执行记录**。录制期间**闸门强制打开**、**鼠标钩子临时挂上**（新建第一条时配置里既没有启用条目、也不会为触摸板挂鼠标钩子，缺任一条采集都开不了），浮层不受排除程序 / 全屏让路抑制；`Esc` 作废这一笔（可再画），「完成」/ 窗口失焦 / 收进托盘即结束会话。
- **入口验收**：录 `CapsLock` → 列表显示触发键徽标 + 方向串 → 真机画一笔命中；关掉面板后触发键回到普通按键（不残留会话）。

### 3.2 TP-07 列表与过滤（✅ V1.93 已落地）

触摸板手势已有自己的数组 `Config.touchpad_gestures`（`TouchpadGesture`），不再借 `Config.gestures` + `trigger` 分流：列表行 `touchpadRow`（触摸板图标 + 触发键徽标 + 方向串）、搜索也认触发键、`order` 用本组序列（不与鼠标操作三类跨类型换位）、卡带 `PickKind::Touchpad`、合并 `MergeReport.touchpad_gestures`。真机验收见 `人工验证清单` §77。

### 3.3 TP-10 模板

- 方向串命中的条目**不再被模板改判**（已如此）；
- 模板只在方向串没命中时兜底（已如此）；
- 若要做「纯形状」条目（`pattern` 为空 + 只有模板），要先改三处闸门：`touchpad_gesture_enabled` / `is_touchpad_trigger` / `sanitize_config`（现在空方向串整条被丢），并想清楚判重指纹（空串会互相撞）。**没想清楚之前不做。**

### 3.4 TP-11 / TP-12 平台采集

- macOS：`CGEventTap` 已拿得到 `mouseMoved` 绝对坐标 → 直接喂 `on_move`；`trackpad::supported()` 放开 macOS，真机验「辅助功能」授权、轨迹浮层是否抢焦点（浮层 `focusable(false)` 已保证）。
- Linux：evdev 只有 `REL_X/REL_Y` → 在钩子层累计成虚拟坐标喂 `on_move`（**不移动真光标**，因此 `anchor` / 光标复位在 Linux 上无意义，需要 `supported()` 之外再加一个「是否需要复位」的能力位）。
- 两者都要补 `人工验证清单` 对应小节。

### 3.5 TP-13 多指离散手势（独立路线）

按可行性调研 §3 的伪 `Key` 方案：Linux 走 libinput path 后端拿 `SWIPE` / `PINCH` / `HOLD`；macOS 走私有 `MultitouchSupport`（另授「输入监控」）；Windows 暂缓（需解析 HID 且系统手势仍生效）。落地时要同步 `Key::ALL` 与前端 `KEY_OPTIONS`（`frontend_key_table_matches_core` 守着），并在 `PlatformCaps` 里如实标注。

## 4. 设计决定（已定格，别再翻案）

| 决定 | 理由 |
|------|------|
| 触发源 = 按住一个**键盘键**（`TouchpadGesture.trigger`，必填、只能键盘键） | 复用现成的触发 / 冲突 / 卡带链路；不新增 `Trigger` 变体，爆炸半径最小 |
| 触发键是**纯开关**：按下即吞、没有输出、没命中不回放 | 不是右键，没有「右键菜单被抢」的副作用 |
| 不套 `gesture_timeout_ms` | 收尾时机是松键；「画太久」在触摸板上是正常的 |
| 停手 > 3s（`IDLE_LIMIT`）松键即作废 | 用户走神 / 改主意时别拿半截轨迹执行 |
| 采集中按 Esc = 作废（按下 + 抬起都吞） | 手指还在板上，需要一个中途退出的口；吞抬起是避免应用收到孤立 keyup。**Esc 自己作触发键时不撤销** |
| 前台切换 / 钩子重装 / 配置整份换掉 = `trackpad::reset()` + 收浮层 | 与 `Engine::reset` 同一口径：缓冲里的丢弃、不回放 |
| 采集期间吞左右键、滚轮 = 双指 → 放弃 | 宁可不识别也不判错（「只画圈」的截图确认逻辑在右键手势里，不在这条路） |
| 松键后光标回起笔点（`anchor`） | 这一笔只是「借道」屏幕；不复位会打乱用户正常用鼠标 |
| 识别尺度无关（比例阈值），先轴后斜 | 触摸板一笔只有几厘米、采样稀疏；绝对像素阈值必然失效 |
| 模板只兜底、不改判、不旋转 | 别人分享的模板不能锁死本机能匹配的手势；方向对用户有意义 |
| 浮层与右键手势共用（`ensure_gesture_overlay`），轮询快照 | 钩子回调不能建窗 / 推事件；视觉设置 `GestureVisual` 仍是同一套（一块窗），但**功能参数各有各的**（见下条） |
| **独立开关与参数**（`Settings.touchpad` / `touchpad_start_distance` / `touchpad_exclude`），不借 `Settings.experimental` / `gesture_start_distance` / `gesture_exclude` | 两类触发方式与手感都不同：右键的「起手距离」是「起点之后开始画」，触摸板的「起手距离」是「这一笔至少多长」；排除名单也是「抢不抢右键」与「吞不吞触发键」两种语义。共用一枚开关会让「只想用触摸板」的人被右键手势的副作用拦住，反之亦然。**V1.93 的「设置页不新增触摸板开关」已被这条取代** |
| **独立数组**（`Config.touchpad_gestures`）而不是 `Gesture.trigger` 分流 | 触发方式 / 吞吐口径 / 列表分组 / 展示顺序都不同；老字段留着当兼容入口只会让每次读写都要额外判一次「这类到底算哪种」，也让列表、拖动、卡带、合并各处分叉。`migrate` 一次搬完，之后就只有一个口径 |
| 录入走**独立模式**（模式下拉「触摸板手势」），不是鼠标操作编辑器里的触发方式下拉 | 分类独立之后下拉已无意义（那里只剩右键手势）；独立模式让按键框、保存校验（触发键必填）、列表分组与卡带都自然对齐。**V1.92 的「下拉不新增模式」已被这条取代** |
| 「录入」**复用同一个 `set_sink` 出口**（`TRACKPAD_RECORD` 分流）+ 录制期**强制开闸、临时挂鼠标钩子** | 单例出口按标志分流，不新开第二套钩子 / 状态机；新建第一条时配置里没有启用条目，不开闸就永远录不了；没有鼠标钩子就收不到触摸板合成的移动，同样一笔都录不到 |
| 录制**只回填、不执行**；窗口失焦 / 收进托盘即结束会话 | 回填走与运行时同一套识别函数（录出来的就是跑出来的）；会话不结束 = 触发键被钩子永久吞掉 |

## 5. 已知坑与取舍

- **前台切换会放走触发键的 keyup**：`reset()` 清掉 `armed` 后，抬起的键不再被吞，应用会收到一个孤立 keyup。这是「不执行 + 不残留半截轨迹」的代价，可接受；改它要先把「钩子重装时 keyup 永远丢失」这条一并想清楚。
- **指针加速改变弧长分布**：方向不变，但段长比例会变；改识别阈值必须真机画。
- **采样会被系统合并**：`MIN_STEP = 1px` 已经是下限；点数 < 15 说明驱动合并严重（非精确触摸板 / 低回报率），只能靠平滑与重采样兜。
- **tap-to-click 在采集期间被吞**：这是设计（防误点），别当 bug。
- **多显示器 + DPI**：轨迹点是物理坐标，浮层本地坐标 = 点 − 浮层原点，再除 `scale`；改浮层建窗代码时别丢这一步。
- **浮层必须 `focusable(false)` + 鼠标穿透**：否则抢前台 → `ResetWatch` 误判复位、还会吃掉画手势的移动。
- **`trackpad::drawing()` = `armed()`**：作废后（Esc）仍然为真，直到松键；浮层要靠空点集 / 显式 `hide_gesture_overlay` 收起，别只看 `drawing()`。
- **「录入」期间别切走窗口**：主窗口失焦 / 收进托盘会主动结束会话（前端 `activeCaptureCleanup`）；不去结束的话 `TRACKPAD_RECORD` 会一直挂着，触发键被钩子永久吞掉而面板看不见。
- **迁移只走 `Config::migrate`，别在 `sanitize_config` 里搬**：加载路径只 `migrate()`、保存 / 导入路径才 `sanitize()`；把搬迁写在清洗里会让「读出来看一眼就写回」的路径丢条目。`Gesture.trigger|template` 现在是兼容字段，清洗完要清空，免得又被写回磁盘。
