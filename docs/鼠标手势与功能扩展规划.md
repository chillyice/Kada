## 2. 功能全景（从外部设置界面反推）

> 这一节只描述**功能类别**，不绑定任何具体产品。作用是给 Kada 的功能扩展列一张完整候选表。

### 2.1 触发源

| 触发源 | 行为 |
|---|---|
| 右键拖拽手势 | 按住右键画轨迹，松手按形状/方向串触发动作 |
| 右键按住 + 滚轮 | 按住右键时滚轮执行切换动作 |
| 屏幕边缘 + 滚轮 | 光标在屏幕上/下/左/右边缘滚动或按下时触发 |
| 屏幕四角 | 光标移到四个角触发 |
| 全局热键 | 组合键直接触发 |
| 按键双击 / 长按 | 双击复制后弹菜单等复合触发 |

### 2.2 行为开关与体验项

| 功能 | 行为 |
|---|---|
| 手势开关 / 起手距离 / 停顿超时 / 灵敏度 | 控制手势是否触发与手感 |
| 手势视觉 | 轨迹线、末端箭头、结果提示、颜色、宽度、字号、偏移 |
| 手势添加模式 | 画出未识别手势时打开新增界面 |
| 排除列表 | 指定程序内不启用功能 |
| 忽略全屏 | 前台全屏程序时自动暂停 |
| 快捷菜单（复制增强） | 选中文字后双击 Ctrl+C 弹动作菜单 |
| 按键回显 | 屏幕显示当前按键，可配颜色/位置/字号/消失时间 |
| 全局全屏暂停 | 全屏程序内所有触发暂停 |
| 管理员运行 / 开机启动 / 托盘图标 | 启动与常驻行为 |
| 多语言 | 界面语言切换 |
| 自然滚动 / 滚轮穿透 / 大写锁定提示 / 输入法状态 / 快速跳转 / 自动复制 / 快速粘贴 / 音量回馈 / 按键音效 | 系统级或输入技巧类体验项 |

### 2.3 动作库

| 类别 | 动作 |
|---|---|
| 窗口 | 最大化/还原、最小化、置顶、居中、关闭、关闭同类窗口、隐藏到托盘、恢复托盘、切换托盘 |
| 程序内部 | 退出、暂停/恢复、隐藏托盘图标、打开快捷菜单、当前程序加入排除、重载配置、改配置、打开设置、延迟、打印、右下角提示、临时取选中文字 |
| 按键 | 发送组合键、单键按下/抬起、不激活窗口发送 |
| 鼠标 | 激活窗口、左/右/中/侧键点击、移动到绝对坐标或手势起点 |
| 剪贴板 | 设置剪贴板、读剪贴板（文本/图片）、临时取选中文字 |
| 执行 | 运行命令 / 打开网页，支持隐藏窗口、管理员、等待结束、环境变量与内置变量 |
| 截图 | 手势区域截图、框选截图、窗口高质量截图；出口剪贴板、文件、贴图、画中画、OCR |
| 算法 | base64、url 编解码、md5、sha1、sha256、二维码 |
| 资源管理器 | 定位文件、清空回收站、关闭显示器、切换桌面图标 |
| 系统 | 亮度调节、发送窗口消息、写注册表 |

### 2.4 配置模型结论

- 外部配置常见形态：整份 JSON + 字符串元组动作 + 原始点手势模板。
- Kada 形态：整份 JSON + 类型化动作对象 + 方向串手势 + `when` 条件。
- **不直接导入外部配置**：格式、手势表示、动作集、失败行为都不同；真要做只能写一次性转换器，优先级低于功能扩展。

### 3.4 主要缺口

- 手势只有识别，没有**视觉反馈与可调参数 UI**；
- 没有**触发角 / 边缘滚动 / 按键回显 / 快捷菜单**；
- 动作缺**当前窗口操作 / 剪贴板写入读取 / 绝对坐标 / 按下抬起 / 截图 / OCR**；
- 全屏暂停的默认行为只作用于手势；快捷键 / 改键等的全屏暂停需显式打开 `Settings.ignore_fullscreen`（EXT-05，全局排除列表已由 EXT-04 补齐）。

### 4.3 Kada 独有、扩展时不能丢

- 改键全形态、层、序列/和弦、文本扩展；
- `when` 条件、变量、`If` / `Parallel` / `Group` / `Script`；
- 执行记录 / 消息中心 / 超时中止 / 进程树清理；
- 配置原子写 / 外部改动监听 / 导入合并 / 同步存档；
- 卡带市场 / 软件更新 / 三平台输入层；
- 输入层环境诊断 / 提权注入 / HID++ 解锁。

### 4.4 配置互通性（结论：不直接导入）

| 维度 | 外部实现 | Kada |
|---|---|---|
| 动作 | 字符串元组 `["Window","Minimize"]` | 类型化对象 `{"type":"app","operation":...}` |
| 手势 | 原始点模板 | 方向串 + `when` |
| 失败行为 | 可配置是否还原右键 | 未命中必须回放右键 |
| 配置通道 | 整份 JSON + 本地服务 | 整份 JSON + 原子写 + 外部监听 |

**结论**：只扩展功能，不做配置导入；如未来要做，单独写一次性转换器，不混进主链路。

## 5. 鼠标手势专项方案

### 5.1 结论摘要

| 问题 | 结论 |
|---|---|
| 能不能做 | **能**。Windows 鼠标钩子本来就装；macOS 需补两个事件掩码；Linux 已有 `BTN_RIGHT` + `REL_X/Y` |
| 代价多大 | **体积几乎为零**（实测 exe +60~120 KB、安装包 +30~80 KB，<1%）；真正代价是行为风险（全局抢右键） |
| 能不能直接吃外部配置 | **不能**。配置格式、手势表示、动作集、失败行为四层都对不上 |
| 建议 | V1 只做「方向串手势 + 滚轮键」；任意形状模板放 V1.1；边缘/触发角放 V2 |
| 最大未决项 | ① 未命中回放右键会不会干扰日常右键 ② 没有排除程序时是否敢默认开启 |

### 5.2 当前落地状态

- **V1 已落地（7.1-MG）**：手势采集（仅 Windows）+ 方向串识别 + 未命中回放右键。
- 入口：`快捷键` 页的 `鼠标操作` 分类（与快捷键 / 改键 / 文本扩展并列）。
- 总闸：设置页「实验功能」卡片的 `Settings.experimental`（默认关；关掉 → 分类不出现、行为不生效、配置保留）。
- 已落地余项：手势 `when` 条件、排除程序 `Settings.gesture_exclude`、全屏自动暂停、手势进卡带（`PickKind::Gesture`）、滚轮快捷键（Windows）、手势视觉（EXT-02，轨迹线 / 末端箭头 / 结果标签 / 失败色）。
- 未做：滚轮快捷键 macOS / Linux、手势 macOS / Linux、任意形状模板。
- 真机状态：真手势尚未完整复跑，见 `docs/人工验证清单.md` 第 40、41 节。

### 5.3 目标分级

#### V1（已落地，Windows）

| 能力 | 验收标准 |
|---|---|
| 右键拖拽手势（方向串，8 方向） | 画 `↓→` 触发复制；画 `DRUL` 触发「打开记事本」 |
| 未命中回放右键 | 画错方向 → 右键菜单照常弹出（延迟 ≤ 30 ms） |
| 不影响左键 / 其它键 | 左键、右键单击、滚轮、键盘照旧 |
| 命中后复用现有引擎 | 动作链、层、`when`、并行、记录、消息全部复用 |
| 配置全链路 | 保存 / 外部监听 / 导入导出 / 合并 / 同步存档 / 冲突提示都不丢手势段 |

#### V1.1（手感补丁）

- 任意形状模板匹配（S / P / 圆圈）；
- 轨迹浮层（原生 GDI 折线，或 Tauri 窗口 + canvas）；
- 灵敏度 / 起手距离 / 超时可在 UI 调；
- 手势按程序限定（复用 `when`）。

#### V2（长尾）

- 滚轮快捷键 macOS / Linux 接线；
- 手势 macOS / Linux 接线；
- 右键+滚轮、屏幕边缘滚轮、触发角；
- 绝对坐标移动、手势起点变量、执行前激活手势起点窗口；
- 手势进卡带（已部分落地）。

#### 明确不做

- 直接导入外部配置 / 写转换器（成本高于收益）；
- 截图 / OCR / 贴图 / 按键回显 / AltDrag / 剪贴板增强（属独立功能扩展，见第 6 节，不混进手势主链路）；
- 键模型里加入右键 / 左键（会污染快捷键、改键、冲突检测、录入四条链路）。

### 5.4 数据模型

当前实际模型（以源码为准）：

```rust
Gesture {
    name: Option<String>,
    pattern: String,          // 方向串
    actions: Vec<Action>,     // 复用现有动作
    when: Option<Condition>,  // 复用触发侧条件
    enabled: bool,
}
```

`Settings` 已有：

```rust
gesture_start_distance: i32,   // 起手距离
gesture_timeout_ms: u64,       // 停顿超时
gesture_min_segment: i32,      // 最小方向段长
gesture_exclude: Vec<String>,  // 排除程序
gesture_trail_color: String,   // 轨迹颜色（#RRGGBB）
gesture_trail_width: i32,      // 轨迹线宽
gesture_label_font_size: i32,  // 结果标签字号
gesture_label_offset: i32,     // 结果标签偏移
gesture_fail_color: String,    // 未命中失败色
```

**序列化约定**：`#[serde(default)]` + 缺失字段回落默认值 → 旧配置可加载；旧版 Kada 读到带 `gestures` 的配置会丢掉该段（前向不兼容，已知代价）。

### 5.5 方向串约定

| 记法 | 含义 |
|---|---|
| `U` / `D` / `L` / `R` | 上 / 下 / 左 / 右 |
| `UR` / `DR` / `DL` / `UL` | 四个斜向 |
| `↑` `↓` `←` `→` `↗` `↘` `↙` `↖` | 箭头别名（加载时归一化） |
| `UP` / `DOWN` / `LEFT` / `RIGHT` / `UPRIGHT` … | 兼容词形（归一化后等价） |

### 5.6 识别算法（纯函数，`kada-core`）

```
输入：轨迹点序列 (x, y)[]、起手距离、方向段长
输出：方向串 "DRUL"
```

1. **起手判定**：累计位移 > `start_distance` 才进入「正在画」；之前只吞不画。
2. **方向量化**：从锚点累积到 ≥ `min_segment` 的位移，取与屏幕坐标（y 向下）夹角 → 8 方向桶；相邻同向合并（`DDD` → `D`）。
3. **归一化**：配置串与识别串都归一化后比较。
4. **匹配**：**精确匹配**（不做前缀匹配，避免 `D` 与 `DR` 互相吃）。同 pattern 多条 → 冲突检测给 Warn，按配置顺序取第一条。
5. **抖动**：靠「段长阈值 + 同向合并」吸收，无需额外滤波。
6. **超时**：绘制途中静止超过 `timeout_ms` → 取消本次手势，抬起时按「未命中」处理（回放右键）。

### 5.7 三平台接线

统一形状：`kada-hook` 暴露平台无关的「手势采集器」：

```
set_gesture_enabled(bool)    // 壳层按配置推送（独立于 config_uses_mouse）
set_stroke_sink(fn(Stroke))  // 松手时把轨迹交出去（识别在壳层做）
```

| 平台 | 接线 |
|---|---|
| Windows | `mouse_proc` 处理 `WM_RBUTTONDOWN` / `WM_MOUSEMOVE` / `WM_RBUTTONUP`；复用「按下-抬起配对吞键」语义 |
| macOS | `events_of_interest()` 补 `RightMouseDragged` / `RightMouseUp`；回调不许做耗时操作 |
| Linux | `BTN_RIGHT` + `REL_X/REL_Y`；吞右键 = 不转发给 uinput；回放走 `simulate` |

**壳层（`src-tauri`）**：

- 定时器线程（`spawn_engine_ticker`）比对配置 → 推 `set_gesture_enabled`。
- 收到 `Stroke` → 后台线程识别 → 命中走现有动作执行路径（`fire` / 记录 / 消息上报）；未命中走注入路径回放右键（`deliver`，提权窗口走伴随进程）。
- **手势不进 `Engine::step`**：它不是键序列，绕进去会污染 tap-hold / 和弦 / 序列状态机。

### 5.9 风险与已知天花板

| 风险 | 级别 | 说明 | 缓解 |
|---|---|---|---|
| 全局抢右键 | 高 | 右键拖拽在游戏 / CAD / 远程桌面 / 拖文件里是正常操作；被吞后即使回放也只是「点击」，拖拽语义已丢 | 默认关闭 / 排除程序 / 全屏暂停 / 托盘一键暂停 |
| 回放延迟 | 中 | 未命中时右键菜单晚 ~10~30 ms | 试验台用 10 ms；可调；命中路径无延迟 |
| 右键单击也走吞→回放 | 中 | 每个右键都要判定 | 起手距离 + 只在启用手势时吞 |
| 方向串手感 | 中 | 8 方向 + 段长阈值 ≠ 任意形状；抖动 / 弧线识别不到 | V1 接受；V1.1 上模板 |
| macOS 事件掩码 | 中 | 需补 `RightMouseDragged` / `RightMouseUp`；tap 回调对耗时敏感 | 识别在壳层线程 |
| Linux 只有相对位移 | 低 | 方向串只依赖位移 → 可用；绝对坐标 / 边缘 / 触发角在 Wayland 下受限 | V2 明确标注受限 |
| 浮层抢前台 | 中 | 轨迹层若可激活会被判成前台切换 → 误触发 `ResetWatch` | `WS_EX_NOACTIVATE` + `WS_EX_TRANSPARENT` |
| 多显示器 / DPI | 中 | 轨迹层跨虚拟屏坐标 + 缩放 | 进程声明 per-monitor DPI aware；坐标用物理像素 |
| 钩子被静默摘 | 低 | 与现有看门狗同源 | 复用 `reinstall_count()` / 心跳 |
| 与厂商软件并存 | 低 | 厂商软件 divert 的是侧键，不影响右键 | 诊断口径别混 |

### 5.12 验收标准

1. 按住右键画 `↓→` → 复制动作触发，轨迹层显示方向串。
2. 按住右键画一个**未配置**的方向 → 右键菜单照常弹出（不得消失、不得变成别的动作）。
3. 右键单击（不动）→ 菜单正常弹出，延迟 ≤ 30 ms。
4. 左手拖拽文件（Explorer）→ 不被劫持（前提：未配置匹配方向；否则记为已知限制）。
5. 手势执行中右键**不残留**（不出现「一直按着右键」的状态）。
6. 关闭「启用手势」→ 右键完全回到系统行为；删除全部手势 → 鼠标钩子按需卸下。
7. 钩子重装 / 切前台 / 锁屏唤醒后 → 手势状态复位，不残留半截轨迹。
8. 注入事件（`Action::Click` / 回放右键）不触发手势。
9. 配置改动（外部 / 导入 / 合并）后手势不丢、不冲突。
10. macOS / Linux：至少编译通过 + 登记为「待真机」。

### 5.13 待决策

1. **V1 是否接受方向串而不是任意形状模板？** 建议接受（工期差 3~5 天，手感可调）；若目标用户强依赖字母形状，模板匹配要提到 V1。
2. **未命中是否回放右键？** 建议回放（符合吞键铁律）；代价是「画错一笔会弹菜单」。也可做成配置项 `gesture_restore_event`。
3. **是否默认开启？** 无排除列表时建议默认关闭 + UI 显式提示风险；或默认开启但把起手距离调大。
4. **右键单击也走「吞→回放」？** 影响每个右键延迟；备选「按下先不吞，位移超阈值才吞」不可行（菜单已弹出无法撤回），只能先吞后回放。
5. **手势是否参与层 / 卡带 / 同步？** V1 建议不参与层；卡带已支持；同步走整份 JSON 自然包含。

## 7. 设置界面形态

### 7.1 建议结构

```text
设置
├─ 外观           主题 / 语言（含 zh-TW）/ 状态 HUD / 提示框
├─ 启动与暂停     开机自启 / 暂停 / 唤醒键 / 全屏自动暂停
├─ 时序与注入     序列超时 / 和弦超时 / 动作超时 / 文本注入方式
├─ 鼠标手势       开关 / 起手距离 / 超时 / 灵敏度 / 视觉 / 排除程序
├─ 额外触发       触发角 / 边缘滚动 / 快捷菜单
├─ 显示           按键回显 / HUD / 提示框
├─ 动作           窗口 / 剪贴板 / 截图（如果做）
├─ 输入环境诊断
├─ 提权
└─ 配置与更新     导出 / 导入 / 示例 / 卡带市场 / 同步 / 更新
```

### 7.2 外部设置页 → Kada 落点

| 外部设置页 | Kada 落点 | 合并方式 |
|---|---|---|
| 快速设置 / 功能开关 | 设置页「启动与暂停」「鼠标手势」「额外触发」「显示」 | 拆成对应卡片，不保留单独「快速开关」页 |
| 排除列表 | 设置页「鼠标手势」+ 全局排除卡 | 一个列表，标注「全部功能 / 仅手势」 |
| 手势设置 | 设置页「鼠标手势」 | 直接并 |
| 手势列表 | 快捷键列表「鼠标操作」分类 | 已有，不新建页 |
| 通用动作 / 特定动作 | 快捷键列表 + `when` / 文件夹 | 用「程序分组」视图呈现，不复制全局/特定双表 |
| 动作示例 | 示例 + 卡带市场 | 已有 |
| 边缘滚动 / 触发角 | 「额外触发」设置卡或列表类型 | 新增触发类型，不新建独立页 |
| 快捷菜单 | 「额外触发」设置卡 + 菜单编辑 | 新增 |
| 全局热键 | 快捷键列表 | 已有 |
| 按键回显 | 设置页「显示」 | 新增卡片 |
| 多语言 | 设置页「外观」 | 已有，补语言 |

**原则**：不照搬外部产品的页面数量，而是把「触发方式」统一进快捷键列表/额外触发，「行为开关」统一进设置卡片。

- [ ] 改文档：`node scripts/check-docs.mjs`；
- [ ] 真机项写进 `docs/人工验证清单.md` 并跑完回填。

### 8.2 不能破坏的不变量

- 未命中的鼠标手势/触发角/边缘操作必须**原样回放**，不吞用户输入；
- 新增浮窗必须 `focusable(false)`，不能抢前台导致 `ResetWatch` 误复位；
- 新增配置字段必须走 `sanitize_config` / `merge_configs` / 外部监听 / 同步存档；
- 新增注入路径必须经 `deliver()`，并处理提权窗口回落；
- 新增鼠标用途必须同步 `config_needs_mouse_hook`，但**不要**把新用途混进 `config_uses_mouse` 的诊断口径；
- 新增动作必须上报 `ActionStep`，并接入超时/中止。
