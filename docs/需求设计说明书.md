## 1. 产品概述

咔哒 Kada 是轻快跨平台快捷键工具：全局键盘快捷键、改键、宏，桌面托盘常驻（关窗不退出），配置以 JSON 落盘、可跨平台同步。

- 目标平台：Windows、Linux（已实现）；macOS（M5 规划）。
- 无后端服务、无数据库，纯本地运行。
- 运行时配置落盘在 Tauri `app_data_dir()/config.json`。

## 2. 键模型（kada-core）

### 2.1 类型

| 类型 | 说明 |
|------|------|
| `Modifier` | `Ctrl / Alt / Shift / Meta`（跨平台中性名；macOS 的 ⌘ 即 Meta） |
| `Key` | 字母 A-Z、数字 0-9、F1-F12、标点（`,` `.` `/` `\` `;` `"` `` ` `` `-` `=` `[` `]`）、功能键（`Enter/Escape/Tab/Space/Backspace/Delete/Insert/CapsLock`）、修饰键本体（`Shift/Control/Alt/Meta`）、方向/编辑键（`Home/End/PageUp/PageDown/Up/Down/Left/Right`） |
| `RawEvent` | `{ key, mods: BTreeSet<Modifier>, pressed }`，钩子层产出 |
| `Shortcut` | `{ mods: BTreeSet<Modifier>, key }`，一个快捷键组合 |

### 2.2 解析与匹配

- 解析 `"Ctrl+Alt+K"`：`+` 分隔；`Ctrl/Control/Cmd/Win`→Ctrl、`Alt/Option`→Alt、`Shift`→Shift、`Meta/Super`→Meta。单个部分（如 `"Shift"`）按按键处理（改键场景）。
- 渲染：`format_shortcut` / `key_name` 把 `Shortcut`/`Key` 渲染回 `"Ctrl+Alt+K"` 形式（UI 展示与配置落盘共用）。
- 匹配（`matches`）：主键一致 **且** 事件修饰键 ⊇ 快捷键修饰键——按下 `Ctrl+Shift+K` 也命中 `Ctrl+K`（宽松规则）。

## 3. 配置模型（kada-core）

配置是跨平台同步介质，直接以 JSON 落盘/交换；快捷键以 `"Ctrl+Alt+K"` 文本存放（人类可读、可编辑），加载时解析校验。

```rust
Config { shortcuts: Vec<ShortcutItem>, remaps: Vec<Remap> }

ShortcutItem { name: Option<String>, triggers: Vec<String>, action: Action, enabled: bool }
// triggers 任一组命中即触发

Action = Text { text: String }                       // 文本粘贴到当前焦点
       | Sequence { steps: Vec<Step> }               // 顺序动作链（宏）

Step = Text { text }                                  // 输入文本
     | Tap { key }                                    // 点按一个键
     | Keys { keys: Vec<String> }                     // 组合键（如 ["Ctrl","C"]）
     | Down { key }                                   // 按下不松
     | Up { key }                                     // 松开
     | PauseMs { ms: u64 }                            // 暂停

Remap { from: String, to: String, enabled: bool }     // from 键按下改发 to 键
```

- `Action::validate` 校验动作可执行：所有键名可解析（非法返回中文错误）。
- 手工编辑的配置允许缺字段、带未知字段（`#[serde(default)]`），加载时校验；解析失败回退默认空配置。

## 4. 钩子引擎（kada-hook）

职责：把系统键盘事件翻译成 `KeyEvent`，回调处理函数决定 `Action`（`Allow` 放行 / `Block` 吞掉 / `Replace` 注入目标键），注入由 `simulate` 完成。事件统一为轻量键盘事件，键模型在 `kada-core`。

### 4.1 Windows（`win`）

- `SetWindowsHookEx(WH_KEYBOARD_LL)` 全局低层钩子，独立线程跑消息循环；处理函数直接跑在回调内（不做跨线程调度，保证顺序与低延迟）。
- 修饰键用 `GetKeyState` 实时读（事件键自身方向手动修正，避开队列滞后）；自动重复按同键 250ms 内再次 down 识别。
- `Block`/`Replace` 登记 `SWALLOWED`，后续 keyup 一并吞掉防幽灵按键；`Replace` 保持"按下-抬起"配对（按住原键 = 按住目标键）；未吞掉的 keyup 以观察者身份回调 handler（录制宏用），返回值被忽略。
- 注入事件带 `LLKHF_INJECTED` 一律放行，杜绝自我回环。
- `Replace` 注入走 `SendInput`，键码为虚拟键码（US 布局语义，OEM 标点键实际位置因键盘布局而异）。

### 4.2 Linux（`linux`）

- evdev + uinput（内核输入层），X11 / Wayland 通用。
- 打开 `/dev/input/event*` 键盘设备并 `EVIOCGRAB` 独占抓取：被抓设备的所有按键事件只到达我们，原事件不再进应用。
- 用 `/dev/uinput` 建虚拟键盘 `kada-virtual-keyboard`，把 `Action` 结果转发给系统；事件全走 uinput 设备，天然无"收到自己注入事件"的回环。
- 自动重复：物理键长按时内核产生 `value=2` 事件，`Allow` 原样转发、`Replace` 按目标键转发，长按连发不丢。
- 修饰键状态按事件流维护（`MODS_DOWN`），吞键/改键不影响真实状态位，与 Windows `GetKeyState` 语义对齐。
- 授权要求：root 或 `input` 组 + udev 放开 `/dev/uinput`；无权限时 `start` 报错，能读到的其它键盘静默跳过。

### 4.3 注入（`simulate`）

- `down / up / tap / chord / type_text` 与 Windows 后端同接口。
- 文本走剪贴板 + `Ctrl+V`（中文等 Unicode 最稳）；副作用是短暂占用并恢复剪贴板。
- 组合键：全部按下 → 稍停（Windows 30ms）→ 逆序松开。

### 4.4 已知天花板（升级路径）

- 低层钩子拦不住 UAC 提权进程 / 部分游戏 → 驱动级拦截（Interception）。
- `type_text` 用剪贴板粘贴，会短暂占用剪贴板；目标程序吞粘贴（游戏/终端）的场景后续可加 `KEYEVENTF_UNICODE` 直发兜底（两者加开关）。
- Linux 热插拔键盘不在监听列表（重启应用即可）。

## 5. 桌面壳（src-tauri，crate `kada`）

配置驱动：启动时加载 JSON 配置 → 把平台钩子接入配置匹配 → 托盘常驻（关窗不退出）。命令层承载 UI 的读写配置。

### 5.1 事件决策（`decide`）

- 改键优先于快捷键：先消耗原生键，避免改键后键再触发快捷键。
- 快捷键匹配：跳过 `enabled=false` 与自动重复（`repeat`）；`triggers` 里任一组命中即返回 `Outcome::Shortcut(action)`。
- 命中快捷键的动作在异步线程执行（`fire` → `run_action`），避免阻塞钩子回调。

### 5.2 宏录制器（`Recorder`）

- 把全局键盘事件转录成 `Step` 时间线：重复 down 折叠；事件间时差 ≥20ms 补 `PauseMs`；键名落盘为可读字符串。
- 录制中快捷键/改键全暂停，所有事件进时间线、放行；结束补全仍在按住的键的 keyup。

### 5.3 Tauri 命令（UI 调用）

| 命令 | 说明 |
|------|------|
| `get_config` | 读取当前配置 |
| `set_config` | 校验并保存配置（写磁盘 + 即时生效，钩子无需重启） |
| `set_paused` | 暂停/恢复快捷键触发（录入组合键时暂停，避免自触发） |
| `start_record` | 开始录制宏（快捷键/改键随即暂停） |
| `stop_record` | 停止录制，返回时间线步骤（可直接作为 Sequence 动作保存） |

- 托盘：`打开咔哒`（显示主窗口）/ `退出`；关窗 = 隐藏到托盘，应用继续跑。
- 跨平台：事件管道用自有 `Ev`，各平台钩子都喂给 `decide` / `Recorder`；非 Windows/Linux 平台（macOS）用占位类型保证壳可编译（改键/快捷键/录制不可用，托盘与配置界面可用）。

## 6. UI（ui，kada-ui）

Vanilla TypeScript + Vite，深色主题。两个标签页：

- **快捷键**：列表展示（开关/触发器/描述/编辑/删除）；编辑器支持录入组合键（`set_paused` 暂停防自触发，Esc 取消）、动作类型切换（文本 / 宏序列）、宏录制（`start_record`/`stop_record` 落成 JSON 步骤）。
- **改键**：列表展示（开关 / from 下拉 / → / to 下拉 / 删除），键名下拉对齐 `kada-core` 的 `key_name`。
