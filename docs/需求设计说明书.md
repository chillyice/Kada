## 1. 产品概述

咔哒 Kada 是轻快跨平台快捷键工具：全局键盘快捷键、改键、宏，桌面托盘常驻（关窗不退出），配置以 JSON 落盘、可跨平台同步。

- 目标平台：Windows、Linux（已实现）；macOS（M5 规划）。
- 无后端服务、无数据库，纯本地运行。
- 运行时配置落盘在 Tauri `app_data_dir()/config.json`。

## 2. 键模型（kada-core）

### 2.1 类型

| 类型 | 说明 |
|------|------|
| `Modifier` | `Ctrl / Alt / Shift / Meta`（跨平台中性名；macOS 的 ⌘ 即 Meta） |
| `Key` | 字母 A-Z、数字 0-9、F1-F24、标点（`,` `.` `/` `\` `;` `"` `` ` `` `-` `=` `[` `]`）、功能键（`Enter/Escape/Tab/Space/Backspace/Delete/Insert/CapsLock`）、修饰键本体（`Shift/Control/Alt/Meta`）、方向/编辑键（`Home/End/PageUp/PageDown/Up/Down/Left/Right`）、媒体键（`MediaPlayPause/MediaPrev/MediaNext/VolumeMute/VolumeDown/VolumeUp`）、NumPad 区（`Numpad0..9/NumpadAdd/NumpadSubtract/NumpadMultiply/NumpadDivide/NumpadDecimal/NumpadEnter`）+ `NumLock`、鼠标键（`MouseMiddle/MouseBack/MouseForward`，即中键/侧键 MB4/MB5） |
| `RawEvent` | `{ key, mods: BTreeSet<Modifier>, pressed }`，钩子层产出 |
| `Shortcut` | `{ mods: BTreeSet<Modifier>, key }`，一个快捷键组合 |

### 2.2 解析与匹配

- 解析 `"Ctrl+Alt+K"`：`+` 分隔；`Ctrl/Control/Cmd/Win`→Ctrl、`Alt/Option`→Alt、`Shift`→Shift、`Meta/Super`→Meta。单个部分（如 `"Shift"`）按按键处理（改键场景）。
- 渲染：`format_shortcut` / `key_name` 把 `Shortcut`/`Key` 渲染回 `"Ctrl+Alt+K"` 形式（UI 展示与配置落盘共用）。
- 匹配（`matches`）：主键一致 **且** 事件修饰键 ⊇ 快捷键修饰键——按下 `Ctrl+Shift+K` 也命中 `Ctrl+K`（宽松规则）。
- 键名别名：媒体/NumPad/鼠标键支持别名（`MB4`/`XButton1`→`MouseBack`、`VolUp`→`VolumeUp`、`NumpadPlus`→`NumpadAdd` 等），渲染统一回规范名。鼠标键不参与修饰键，`"MouseBack"` 即无修饰组合、`"Ctrl+VolumeUp"` 为带修饰组合，均可作快捷键主键或改键 from/to。

## 3. 配置模型（kada-core）

配置是跨平台同步介质，直接以 JSON 落盘/交换；快捷键以 `"Ctrl+Alt+K"` 文本存放（人类可读、可编辑），加载时解析校验。

```rust
Config { folders: Vec<Folder>, shortcuts: Vec<ShortcutItem>, remaps: Vec<Remap>, settings: Settings }

Folder { id: String, name: String, parent: Option<String> }  // 目录树分组（可嵌套，仅影响展示/排序）

ShortcutItem { name: Option<String>, description: Option<String>, folder: Option<String>,
               triggers: Vec<String>, actions: Vec<Action>, enabled: bool }
// triggers 任一组命中即触发；actions 按顺序执行

Action = Text { text: String, mode: TextMode }      // 文本粘贴到当前焦点（mode：原样 / 选中转大写 / 转小写）
       | Command { shell: Shell, command: String, show_output: bool }  // 执行命令（Shell=Cmd/Powershell）
       | Keys { keys: Vec<String> }                         // 组合键（如 ["Ctrl","C"]）
       | PauseMs { ms: u64 }                                // 暂停
       | Os { operation: OsOperation }                      // 文件动作（见下）
       | App { operation: AppOperation }                    // 应用动作（打开/关闭/状态/重启）
       | If { condition: Condition, then: Vec<Action>, otherwise: Vec<Action> }  // 条件判断（真→then，否则→otherwise）

TextMode = Input | ToUpper | ToLower          // ToUpper/ToLower：复制选中→读剪贴板→转换→粘贴
Shell = Cmd | Powershell                      // Cmd=cmd /C（Linux sh -c），Powershell 仅 Windows

OsOperation = Copy { source, dest } | Cut { source, dest } | Paste { dest }
            | Delete { path } | NewFile { path } | NewFolder { path }
            | OpenFolder { path } | Zip { source, dest } | Unzip { source, dest }
            | GetFileProps { path, var }                    // 取属性写入变量 var（FileObject）

AppOperation = Launch { program, args } | Close { program }
             | Status { program, var, retries, interval_ms } | Restart { program, args }
             // Status 写布尔变量；retries/interval_ms 未运行时轮询重试

Condition = Exists { path } | NotExists { path } | IsFile { path } | IsDir { path }
          | Equals { var, field, value } | NotEquals { var, field, value }  // field 空=完整路径
          | ModifiedWithin { path, minutes }                // 最近 N 分钟内被修改

// 旧版动作（Launch/CloseProgram/Cmd/Powershell/OpenFolder）在 Config::migrate 中自动迁移为
// App::Launch/App::Close/Command/Os::OpenFolder（幂等，递归处理 If）

Remap { from: String, to: String, enabled: bool }     // from 键按下改发 to 键
Settings { autostart: bool, paused: bool, launch_minimized: bool, wake_key: Option<String> }
// wake_key：双击该键唤出主窗口（如 "Alt"）；None=关闭快速唤醒
```

- `Action::validate` 校验动作可执行：键名可解析、必要字段非空（非法返回中文错误）。
- `detect_conflicts` 检测内部冲突：硬冲突（重复触发键/重复改键来源/改键遮蔽快捷键）与软冲突（触发键超集重叠）；另有 `SYSTEM_SHORTCUTS` 系统快捷键清单（中性键名），壳层 `get_conflicts` 在其上叠加「系统清单精确命中 + Windows `RegisterHotKey` 真实占用探测」。
- 变量占位符系统：`Value::{File,Bool,Text}` + `Vars = BTreeMap<String, Value>`；`GetFileProps` 写入 `File`（`FileObject`：name/path/dir/stem/ext/size/modified/is_dir）、`Status` 写入 `Bool`。`substitute_vars` 把 `{变量名}` 替换成完整路径（或 "true"/"false"）、`{变量名.字段}` 取字段值，作用域=单次触发内的动作序列；复制/剪切记 `last_copied` 供「粘贴」动作使用；命令字符串同样支持 `{变量名}` 占位符。
- `sanitize_config` 保存前逐条清洗：坏触发键/动作/改键被单独忽略并返回提示（`set_config`/`import_config` 返回 `Vec<String>`），硬冲突不再阻塞保存（仅 UI 提示）；目录做去重、断环、孤儿父置根级、无效引用清空（`clean_folders`）。
- 手工编辑的配置允许缺字段、带未知字段（`#[serde(default)]`），加载时校验；解析失败回退默认空配置。

## 4. 钩子引擎（kada-hook）

职责：把系统键盘事件翻译成 `KeyEvent`，回调处理函数决定 `Action`（`Allow` 放行 / `Block` 吞掉 / `Replace` 注入目标键），注入由 `simulate` 完成。事件统一为轻量键盘事件，键模型在 `kada-core`。

### 4.1 Windows（`win`）

- `SetWindowsHookEx(WH_KEYBOARD_LL + WH_MOUSE_LL)` 全局低层钩子，同一线程跑消息循环；处理函数直接跑在回调内（不做跨线程调度，保证顺序与低延迟）。
- 鼠标钩子只翻译中键与 X 侧键（`WM_MBUTTON*`/`WM_XBUTTON*`，MB4=后退/XBUTTON1、MB5=前进/XBUTTON2）成统一 `KeyEvent`；左右键、滚轮、移动一律放行（不纳入键模型，避免全局误拦截点击）。鼠标键注入走 `SendInput` 鼠标事件（`MOUSEEVENTF_XDOWN/MIDDLEDOWN` 等，`mouseData` 高 16 位承载 X 按钮号）。
- 修饰键用 `GetKeyState` 实时读（事件键自身方向手动修正，避开队列滞后）；自动重复按同键 250ms 内再次 down 识别。
- `Block`/`Replace` 登记 `SWALLOWED`，后续 keyup 一并吞掉防幽灵按键；`Replace` 保持"按下-抬起"配对（按住原键 = 按住目标键）；未吞掉的 keyup 以观察者身份回调 handler（录制宏用），返回值被忽略。
- 注入事件带 `LLKHF_INJECTED` 一律放行，杜绝自我回环。
- `Replace` 注入走 `SendInput`，键码为虚拟键码（US 布局语义，OEM 标点键实际位置因键盘布局而异）。

### 4.2 Linux（`linux`）

- evdev + uinput（内核输入层），X11 / Wayland 通用。
- 打开 `/dev/input/event*` 键盘设备并 `EVIOCGRAB` 独占抓取：被抓设备的所有按键事件只到达我们，原事件不再进应用。
- 用 `/dev/uinput` 建虚拟键盘 `kada-virtual-keyboard`，把 `Action` 结果转发给系统；事件全走 uinput 设备，天然无"收到自己注入事件"的回环。
- 自动重复：物理键长按时内核产生 `value=2` 事件，`Allow` 原样转发、`Replace` 按目标键转发，长按连发不丢。
- 修饰键状态按事件流维护（`MODS_DOWN`），吞键/改键不影响真实状态位，与 Windows `GetKeyState` 语义对齐。
- 授权要求：root 或 `input` 组 + udev 放开 `/dev/uinput`；无权限时 `start` 报错，能读到的其它键盘静默跳过。

### 4.3 注入（`simulate`）

- `down / up / tap / chord / type_text` 与 Windows 后端同接口。
- 文本走剪贴板 + `Ctrl+V`（中文等 Unicode 最稳）；副作用是短暂占用并恢复剪贴板。
- 组合键：全部按下 → 稍停（Windows 30ms）→ 逆序松开。

### 4.4 已知天花板（升级路径）

- 低层钩子拦不住 UAC 提权进程 / 部分游戏 → 驱动级拦截（Interception）。
- `type_text` 用剪贴板粘贴，会短暂占用剪贴板；目标程序吞粘贴（游戏/终端）的场景后续可加 `KEYEVENTF_UNICODE` 直发兜底（两者加开关）。
- Linux 热插拔键盘不在监听列表（重启应用即可）。

## 5. 桌面壳（src-tauri，crate `kada`）

配置驱动：启动时加载 JSON 配置 → 把平台钩子接入配置匹配 → 托盘常驻（关窗不退出）。命令层承载 UI 的读写配置。

- **窗口懒创建（冷启动零 WebView）**：启动时既不建主窗口也不建气泡窗口。主窗口由 `show_main_window()` 按需建出（不存在则 `WebviewWindowBuilder` 建 860×560 居中、已存在则 show+focus；托盘菜单「打开」/托盘双击/`show_output` 弹窗三处入口共用）；气泡窗口由 `ensure_toast()` 在首次触发快捷键时建出（右下角小浮层，点击穿透 + 定位）。

### 5.1 事件决策（`decide`）

- 改键优先于快捷键：先消耗原生键，避免改键后键再触发快捷键。
- 快捷键匹配：跳过 `enabled=false` 与自动重复（`repeat`）；`triggers` 里任一组命中即返回 `Outcome::Shortcut { actions, trigger, name }`（携带触发键与名称，供消息中心展示）。
- 命中快捷键的动作在异步线程执行（`fire` → `run_action`），避免阻塞钩子回调。
- **快速唤醒（`detect_wake`）**：在事件决策前被动检测「双击 `Settings.wake_key`（默认 Alt）≤400ms」，命中则唤出主窗口。只唤出窗口、不拦截按键（唤醒键常是修饰键，拦截会破坏 Alt+Tab / Alt+字母）；两次独立 down（非自动重复）判双击，其间按下其它键则取消上一次计数。

### 5.2 宏录制器（`Recorder`）

- 把全局键盘事件转录成 `Action` 时间线：重复 down 折叠；事件间时差 ≥20ms 补 `PauseMs`；组合键合并成一条 `Keys`，键名落盘为可读字符串。
- 录制中快捷键/改键全暂停，所有事件进时间线、放行；结束补全仍在按住的键的 keyup。

### 5.3 Tauri 命令（UI 调用）

| 命令 | 说明 |
|------|------|
| `get_config` | 读取当前配置 |
| `set_config` | 保存配置（逐条清洗坏条目 → 写磁盘 + 即时生效），返回被忽略条目提示 |
| `get_conflicts` | 计算冲突列表：内部冲突 + 系统快捷键清单命中 + Windows `RegisterHotKey` 探测真实占用（前端实时展示警告） |
| `export_config` | 导出配置到指定路径（JSON） |
| `import_config` | 从指定路径导入配置（解析 + 逐条清洗 → 替换并落盘），返回被忽略条目提示 |
| `set_paused` | 暂停/恢复快捷键触发（录入组合键时暂停，避免自触发） |
| `start_record` | 开始录制宏（快捷键/改键随即暂停） |
| `stop_record` | 停止录制，返回动作时间线（`Keys`/`PauseMs` 等） |
| `get_command_results` | 读取消息中心全部命令结果（最新在前） |
| `get_unread` | 是否有未读命令结果（红点） |
| `mark_results_read` | 标记全部已读（熄灭红点、还原托盘图标） |
| `clear_command_results` | 清空消息中心（同时熄灭红点） |
| `get_toast_payload` | 读取最近一次气泡载荷（气泡窗口懒创建后，前端加载时兜底渲染） |

### 5.4 命令结果通知系统（消息中心）

- 命令类动作（`Cmd`/`Powershell`）触发后**一律**捕获输出（stdout/stderr/退出码）并记入消息中心（内存态，重启清空）。
- `show_output` 开关只决定展示方式：开 → 立即按需创建/显示主窗口并弹出结果弹窗；关 → 不弹窗，托盘图标 + 应用内「消息」入口亮红点。
- 进入「消息」页即标记已读、红点熄灭；消息中心以 tab 区分每条结果（标签 `CMD · 触发键` / `PowerShell · 名称`），`‹ ›` 切换。
- 中文不乱码：Windows 下 cmd 前缀 `chcp 65001>nul & `、PowerShell 前缀 `[Console]::OutputEncoding=...` 统一 UTF-8 解码；Linux 下 CMD 走 `sh -c`。

- 托盘：`打开咔哒`（显示主窗口）/ `退出`；关窗 = 隐藏到托盘，应用继续跑。
- 跨平台：事件管道用自有 `Ev`，各平台钩子都喂给 `decide` / `Recorder`；非 Windows/Linux 平台（macOS）用占位类型保证壳可编译（改键/快捷键/录制不可用，托盘与配置界面可用）。

## 6. UI（ui，kada-ui）

Vanilla TypeScript + Vite，深色主题。左栏图标导航四个页面：

- **快捷键**：列表按目录树分组展示（多层嵌套、按深度缩进、折叠/展开、拖拽排序、三点菜单「新建子目录/重命名/粘贴到/删除」、条目复制/剪切/粘贴）；编辑器支持录入组合键（`set_paused` 暂停防自触发，Esc 取消）、动作类型切换（文本 / 命令 / 按键组合 / 延迟 / 文件动作 / 应用动作 / 条件判断）、宏录制（`start_record`/`stop_record` 落成动作时间线）。文本动作带「原样 / 转大写 / 转小写」模式；命令动作统一 CMD/PowerShell（Shell 下拉）并带「弹窗显示结果」开关；文件动作带子操作下拉（含 新建文件夹/解压/打开文件夹）+ 文件/目录浏览，应用动作带程序浏览 + 参数，条件判断支持递归嵌套 then/otherwise 分支。
- **改键**：列表展示（开关 / from 下拉 / → / to 下拉 / 删除），键名下拉对齐 `kada-core` 的 `key_name`。
- **消息**：命令结果中心（见 §5.4），tab 条 + `‹ ›` 切换 + 清空按钮 + 未读红点徽标；`show_output` 开的结果弹窗复用模态样式。
- **设置**：开机自启 / 暂停所有快捷键 / 启动后最小化到托盘 / 快速唤醒键 / 导出导入配置。

| P1 | M5 macOS 输入层 | 当前为占位类型（壳可编译）；需 CGEventTap 等实现全局钩子 + 注入，接入 `decide`/`Recorder` 后快捷键/改键/录制可用 |
| P2 | 驱动级拦截（Interception） | 解决低层钩子拦不住 UAC 提权进程 / 部分游戏的局限 |

| P2 | Windows 自动更新 | 选型已定：Tauri `tauri-plugin-updater` + GitHub Releases + Ed25519 签名；安装步骤与落地清单见 `docs/安装与更新-Windows.md` |
| P3 | Linux 热插拔支持 | 监听 `/dev/input` 热插拔事件，动态增删设备 |
| P3 | 配置跨平台同步 | 配置已是 JSON 介质，同步通道（云/导出导入）待定 |
| P3 | 动作步骤并行执行 | 当前多个动作/步骤严格串行；规划支持独立步骤（多个按键、进程启动）并行/异步触发，缩短长宏耗时 |
| P3 | 动作流程图（可视化编排） | 在配置界面用可视化节点图编排动作顺序/分支/条件，替代纯列表编辑，降低复杂宏的配置门槛 |
