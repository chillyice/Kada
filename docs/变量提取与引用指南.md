# 变量提取与引用指南（Q&A）

> 本文档内容已内置到软件内「帮助」页（左侧导航「帮助」），供用户直接在应用里查阅；本文件为仓库内的完整版。
> 面向使用者的「变量」快速上手：什么时候需要变量、怎么把数据提取成变量、怎么在后续动作里引用。
> 变量只在本条快捷键**一次触发**内的动作序列里有效，触发结束即清空；不落盘、不跨触发、不跨快捷键。

## 一句话原理

一条快捷键可以挂多个动作，**按顺序执行**。有的动作会把结果「存成变量」，后面的动作用 `{变量名}`（或 `{变量名.字段}`）把这个值填进去。

```
[动作1] 取盘符 → 存入变量 drive
[动作2] 复制文件到 {drive}:\备份\     ← 执行时 {drive} 被替换成盘符
```

## 三种提取变量的方式

| 动作 | 存成什么 | 怎么引用 |
|------|---------|---------|
| 执行命令（填「存为变量」） | 文本：命令标准输出（去首尾空白与换行）+ 退出码 | `{变量名}` 得输出全文、`{变量名.exit_code}` 得退出码 |
| 操作系统 → 获取文件属性 | 文件对象（含多个字段） | `{变量名}` 得完整路径，`{变量名.字段}` 得字段 |
| 应用 → 查询运行状态 | 布尔：`true` / `false` | `{变量名}` |

## 引用语法

- `{变量名}`：取变量的「整体值」——文件属性变量得到完整路径，布尔得到 `true`/`false`，文本（命令结果）得到输出全文。
- `{变量名.字段}`：取变量的某个字段。文件属性变量有 `name/path/dir/…` 等字段；命令结果变量有 `exit_code`（退出码，0=成功）。
- 未知变量/字段**原样保留**成 `{...}`，不会报错、不会中断。

### 文件属性字段一览

`name` 文件名、`path` 完整路径、`dir` 所在目录、`stem` 主名（不带扩展名）、`ext` 扩展名（含点）、`size` 大小(字节)、`modified` 修改时间(Unix 秒)、`is_dir` 是否目录。

## 实战：把文件复制到「盘符不确定」的移动硬盘

场景：下班时把电脑里的文件复制到移动硬盘，但盘符每次插上都不固定（今天 E:、明天 F:）。你知道硬盘的**卷标名称**，却不知道盘符。

思路：先用命令按卷标查出盘符 → 存成变量 → 复制动作里用变量拼路径。

### 第 1 步：执行命令，按卷标取盘符

- 动作类型：**执行命令**
- Shell：**PowerShell**
- 命令：

```powershell
(Get-Volume -FileSystemLabel '我的硬盘').DriveLetter
```

> 把卷标 `'我的硬盘'` 换成你硬盘的实际卷标（资源管理器里看到的名字）。这句只输出一个字母，如 `E`（不含冒号）。

- 「存为变量」填：`drive`

### 第 2 步：复制文件，用变量拼目标路径

- 动作类型：**操作系统（文件/目录）→ 复制**
- 原始路径：`C:\工作\待备份`（电脑磁盘里的文件/目录）
- 目标路径：`{drive}:\备份\`

触发后，`{drive}` 会被替换成第 1 步查到的盘符，实际执行 `E:\备份\`（或当天的盘符）。

### 更稳的写法：先确认硬盘在，再复制

加一个「条件判断」动作，避免硬盘没插时复制到错误路径：

1. 执行命令取盘符 → 存入 `drive`（同上）。
2. 条件判断：**变量字段不等于**，变量名 `drive`、字段留空、值留空 —— 盘符查到（非空）才继续。
3. 复制 → 目标路径 `{drive}:\备份\`。

> 「变量字段等于/不等于」的字段留空时，比较的是变量的整体值（文本变量就是其内容）。盘符没查到会得到空值，条件不成立则跳过复制。

## Q&A

**Q：变量能跨两条快捷键、或下次触发再用吗？**
不能。变量只在当前这一次触发、按顺序执行的动作里有效，触发结束即清空；不落盘、不跨触发。

**Q：命令输出带了换行或空格，会影响路径吗？**
不会。「存为变量」会去掉命令输出的首尾空白与换行，只留内容本身。

**Q：取盘符的命令在 CMD 里怎么写？**
可用 `wmic logicaldisk where "VolumeName='我的硬盘'" get DeviceID`，但输出是带表头的表格，需要自行清洗；PowerShell 那句更干净，推荐用 PowerShell。

**Q：命令的退出码（成功/失败）能拿到吗？**
能。命令「存为变量」后，`{变量名.exit_code}` 得到退出码（0=成功，非 0=失败）；`{变量名}` 仍得到标准输出全文。可配合「条件判断」做「命令失败则…」的分支。

**Q：占位符写错了（变量不存在）会怎样？**
不会报错，`{写错的变量名}` 会原样保留在字符串里，等于没替换。执行后到「消息中心」看结果即可排查。

**Q：变量名有什么限制？**
任意非空字符串即可，别含 `{}`、`.`、空白；建议用简单英文/拼音（如 `drive`、`f`），避免和命令里其它 `{...}` 冲突。

**Q：一次触发能存几个变量？**
不限。按顺序执行，后面的动作可以读前面动作存的所有变量；同名变量后写覆盖先写。
