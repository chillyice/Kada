## 「切换系统代理」补「忽略的地址」多行输入与「本地地址」三态

上一轮（11-16）的代理开关只有一条单行的「排除项」输入，跟 Windows 系统代理对话框对不上：那个对话框是「忽略的地址」多行框 + 「请勿将代理服务器用于本地地址」勾选。这一轮把这两项补齐。

**决策**：

1. **本地地址做成三态下拉，不是纯复选框**：复选框没有「我没碰过」这个状态，缺省 `false` 会在每次开启代理时把用户系统里原有的 `<local>` 悄悄删掉。三态让缺省（沿用系统设置）= 一个字节都不碰，与 `server` / `bypass` 留空沿用现有设置同一口径。
2. **排除项留空时改为「以系统现有列表为底」再合并**：11-16 那版留空是「完全不碰」；现在要加 / 减本地地址标记，必须先读出现有列表，否则一勾「本地直连」就把用户手配的例外全冲了。只有显式填了忽略列表才整串替换（保持原有语义）。
3. **macOS / Linux 用本地名字近似 `<local>`**：Windows 的 `<local>` 是「名字不带点」的通配令牌，macOS 真正的等价物是 GUI 里那个 Exclude simple hostnames，networksetup 没有对应参数；写 localhost / 127.0.0.1 / ::1 覆盖绝大多数「本地服务直连」场景，并在提示里写明差异，不假装三平台完全一致。
4. **忽略的地址改成两行 textarea**：Windows 对话框就是多行框，用户从代理软件里复制一列域名过来最省事；解析仍只走 core 的 `parse_proxy_bypass`，UI 只按同口径数项数。
