# 咔哒 Kada

轻快的跨平台快捷键工具：全局快捷键、改键、键位层、文本扩展、鼠标手势、宏，托盘常驻（关窗不退出）。配置就是一份 JSON，可版本管理、可随身带走。

- 官网下载页：<https://ihomy.top/kada>（Windows 安装版 / 便携版 / Linux 包）
- 更新源：默认 ihomy 镜像（服务器每天从 GitHub 已发布版本同步），可切换为 GitHub Releases

## 它能做什么

| 想做的事 | 在 Kada 里怎么写 |
|---|---|
| 一个键干一串事 | **快捷键** → 挂一条动作链（粘贴文本、发按键、开程序、跑命令、切代理……） |
| 把 CapsLock 改成 Esc | **改键**（普通 / 短按长按不同 / 切层键 / 单次键 / 粘滞键 / 连击不同义） |
| 同一按键在不同场合干不同事 | **键位层**（长按切层键进入）+ **触发条件**（前台程序 / 窗口标题 / 设备 …） |
| 打字时自动补全 | **文本扩展**（输入 `;mail` + 空格 → 展开成邮箱） |
| 按住右键画一笔就执行 | **鼠标操作**（方向串手势；画圈后点左键 = 调 Snipaste 截图） |
| 鼠标甩到屏幕角落就执行 | **角动作** / **边缘滚动** |
| 换台电脑继续用 | 配置 JSON + **同步存档**文件夹 / **卡带**导入导出 / **卡带市场** |

## 快速开始

### 1. 安装

- **Windows**：下载 `Kada_<版本>_x64-setup.exe`（安装版，支持自动更新）或便携版 zip（解压即用，更新时原位替换 `kada.exe`）。安装版与便携版靠「exe 所在目录是否为安装目录」区分，两者不会交叉覆盖。
- **Linux**：deb / AppImage，由 docker 容器构建（`scripts/linux-package/`）。
- **macOS**：universal dmg，由 CI 构建。

首次启动要点：

- **Windows**：装上就能用，无需任何授权。
- **macOS**：系统设置 → 隐私与安全性 → **辅助功能** → 勾上 Kada，否则输入层起不来（应用仍会正常启动，并在「消息」页给出可照抄的指引）。用到「激活应用 / 操作窗口 / 媒体键」时，还会要求 **自动化** 权限。
- **Linux**：输入层直接读内核设备、注入走 `/dev/uinput`，需要权限：

  ```bash
  sudo usermod -aG input "$USER"                       # 读 /dev/input/event*
  echo 'KERNEL=="uinput", MODE="0660", GROUP="input"' | sudo tee /etc/udev/rules.d/99-uinput.rules
  sudo modprobe uinput                                 # 缺失时加载
  ```

  改完重新登录生效。权限没配好时应用照常启动，错误与指引进「消息」页。

### 2. 认一下界面

- **左栏一级页**：快捷键 / 键位层 / 卡带市场 / 消息 / 设置 / 帮助。
- **中间列表**：六类条目合并成一份——快捷键、改键、文本扩展、鼠标操作、角动作、边缘滚动，行首图标区分。支持搜索、快捷筛选、多选、拖拽排序、目录分组。
- **右侧编辑页**：标题与简述、触发方式、动作流程图（可折叠、可拖拽插入位置）、详情页签。
- **关闭窗口 = 收进托盘**，应用不退出。托盘菜单：打开主窗口、暂停 / 恢复所有快捷键、重载配置、退出。双击托盘图标也能唤出窗口。
- 想更顺手，在设置里给某个键配「**快速唤醒**」：双击该键（如 `Alt`）就把主窗口拉到前台。

### 3. 三十秒做出第一个快捷键

1. 点列表栏的「新建」→ 选「快捷键」。
2. 触发方式选**组合**，按下 `Ctrl+Alt+K`。
3. 在动作区点「+ 文本」，输入要粘贴的内容。
4. 保存 → 去任意输入框按 `Ctrl+Alt+K`，文本就会打进去。
5. 打开「消息」页能看到这次的执行记录（每一步做了什么、耗时多少）。

对应的配置长这样（配置文件里的字段就是界面上的字段）：

```json
{
  "shortcuts": [
    {
      "name": "打招呼",
      "triggers": ["Ctrl+Alt+K"],
      "actions": [{ "type": "text", "text": "你好，我是 {date} 的 Kada" }],
      "enabled": true
    }
  ]
}
```

## 功能使用方法

### 快捷键：三种触发写法

`triggers` 是一个数组，里面每一组都能单独触发同一条动作链，三种写法可以混用：

| 写法 | 例子 | 说明 |
|---|---|---|
| 组合键 | `Ctrl+Alt+K` | 按下即触发；修饰键顺序不限 |
| 按键序列 | `F9 J K` | 首键是 **leader**：`F9` 按下后进等待窗（默认 1000 ms，可调 / 0 = 不限）再按 `J`、`K` |
| 和弦 | `F&J`，成员可带修饰如 `Ctrl+F & J` | 多个键**同时按住**才触发；等待窗默认 1000 ms |

- **没凑齐不吞键**：序列断链 / 超时、和弦成员全部抬起仍未凑齐，被按下的键会**按原顺序回放**，不会凭空消失。
- **冲突检查**：同一触发写法重复、键位层里同一键冲突、平台能力不支持（如 Linux 上用了绝对坐标鼠标）都会在保存前提示。软冲突只警告、不拦保存。
- **多组触发**：允许 `["Ctrl+Alt+K", "F9 J K"]`，任一组命中即执行。

### 动作：一条链能干什么

一条动作链按顺序执行，常用的这些都能直接在界面里拼：

| 动作 | 用途与关键参数 |
|---|---|
| **文本** | 粘贴一段文本；`mode` 可选原样 / 选中转大写 / 转小写。勾「隐藏内容」后界面显示 `***`（注入内容不变），给口令用 |
| **请求输入** | 弹输入框把结果写进变量；关掉「弹框」则直接把默认值（支持占位符）写进变量，适合做「固定口令 + 脚本」 |
| **按键组合** | 发任意组合键；三种模式：点按 / 按住（链结束自动抬起）/ 抬起 |
| **鼠标** | 移动（相对 / 绝对）、移到手势起点、点击（左 / 右 / 中 / 侧键）、滚轮 |
| **命令** | 跑 CMD / PowerShell：工作目录、参数、超时、算成功的退出码、弹窗口径、「上一次没跑完怎么办」、输出写入变量 |
| **外部脚本** | 跑 `.py` / `.sh` / `.bat`…，可指定解释器与参数；同样有超时、退出码、输出入变量 |
| **内置脚本** | 内置 Rhai 沙箱：不读写文件、不联网、不起进程，用来算字符串 / 拼值 / 做判断 |
| **文件 / 文件夹** | 复制、移动、删除、新建、打开、定位、压缩、解压、取属性 |
| **操作系统** | 切换虚拟桌面、清空回收站、关闭显示器、显示 / 隐藏桌面图标、显示器亮度、**切换系统代理**、向非前台窗口发送按键 |
| **应用** | 启动 / 关闭 / 最大化 / 最小化 / 激活 / 重启，查运行状态写进变量；**当前窗口**动作族（对触发那一刻的前台窗口操作：最大化还原 / 最小化 / 置顶 / 居中 / 关闭 / 关闭同类） |
| **打开网址** | 用系统默认浏览器打开；没写协议头自动补 `https://` |
| **延迟** | 等若干毫秒 |
| **等待条件** | 等文件出现 / 进程起来 / 窗口出现（窗口仅 Windows），可超时，可把实际值写进变量 |
| **条件判断** | 真 → then，否则 → otherwise |
| **并行** | 成员同时开跑，**全部结束才进下一步**；注入类动作之间仍串行（共用一把注入锁） |
| **分组** | 纯组织结构，成员按顺序执行；只影响编辑页与执行记录的层级 |
| **轮巡** | 同一触发每按一次只执行组里的**下一个**成员，循环往复（轮到的位置只在本次运行内，重启从第一个开始） |
| **禁用** | 每条动作右侧的开关：内容保留，执行时整条跳过、不占执行记录 |

链里的通用规则：

- **变量**：内置 `{date}` / `{time}` / `{clipboard}`；任何「写入变量」的动作（命令输出、脚本输出、读剪贴板、取文件属性、请求输入、等待条件…）产生的值，后续动作用 `{变量名}` 引用。
- **失败与超时**：命令 / 脚本默认 30 秒超时（可全局改、也可单步改），超时或点「停止执行」会**杀掉整棵进程树**；每步可设失败后继续还是停整条链。
- **执行记录**：一次触发 = 一条记录，每个动作都留一步（文本、延迟也不例外），分组 / 并行 / 轮巡的成员挂在父步骤下。命令输出、失败原因、中止都进「消息」页。

### 改键

改键改变的是**按键本身**，对所有程序生效（快捷键只在自己的触发写法命中时出手）：

| 形态 | 写法 | 例子 |
|---|---|---|
| 普通 | `from` → `to` | `CapsLock` → `Escape` |
| 短按 / 长按（tap-hold） | `tap` / `hold`，阈值可调（默认 200 ms） | 短按 `Space` 出空格，长按出 `Shift` |
| 连击不同义（tap-dance） | `tap2` / `tap3` | 单击出 `A`、双击出 `B`、三击出 `C` |
| 单次键（oneshot） | `oneshot` | 单击一次 = 下一次按键带上该修饰键 |
| 粘滞键（sticky） | `sticky` | 单击锁定、再单击解锁（侧键做「按住说话」） |
| 长按进入层（momentary） | `hold_layer` | 按住 `CapsLock` 进入「符号层」，松开退出 |
| 长按锁定层 | `lock_layer` | 长按 `CapsLock` 切进「符号层」，再长按退出 |

- 形态**互斥**，同时填了多个时优先级是 `sticky > oneshot > tap-hold > 普通 to`；`hold_layer` 与 `lock_layer` 同设时保留 `lock_layer`。
- 每个改键都能设**归属层**与**触发条件**，条件不成立就等于这条不存在（落到下一条同键条目，不吞键）。

### 键位层

- 层是「一套额外的键位规则」：**激活层里的条目优先，基础层条目兜底**。
- 进入方式只有两种：长按切层键（按住期间有效）或长按锁定（切换式，一直有效到再长按一次）。
- 按住式层（momentary）只有在你**按住切层键期间又按了别的键**（roll）时才真正进入；只按住、不按别的键不算激活（松开时按短按口径处理：配了 `tap` 就输出 `tap`，没配就回放原键）。
- 每层可以配一个**颜色或 emoji 标记**（颜色全机唯一），列表条目的组合键 chip 左下角会带这个角标，一眼看出归属。
- 层内放和弦 / 序列建议用**切换式**切层键（按住式在等待第二个键时会互相打架）。

### 文本扩展

- 输入触发词 + 后缀（空格 / 回车 / Tab）后自动替换成一段文本；触发词长度、重复触发都会在保存前校验。
- 替换文本支持 `{date}` / `{time}` / `{clipboard}` 动态片段。
- 同样支持目录分组、启用开关。它和「快捷键 + 文本动作」的区别是：**由你正常打字触发**，不是按键组合。

### 鼠标：手势 / 截图 / 滚轮 / 角动作 / 边缘滚动

鼠标类功能统一由设置里的「**启用鼠标操作**」总开关控制（默认关）。关掉只是入口隐藏、行为不生效，配置全部保留。

- **手势**：按住**右键**画轨迹，松手时按**方向串**匹配——单段 `U` / `D` / `L` / `R`，斜向 `UR` / `DR` / `DL` / `UL`；多段用逗号，如 `D,R`（先下再右，和一段斜向 `DR` 是两条不同手势）。相邻重复自动去重。
  - 未命中（或没画出足够长的轨迹）**必定回放一次右键**，右键菜单不会丢。
  - **画圈截图**：画一个圈后**不松右键**再点一下左键 → 调 Snipaste 的 `F1` 截图（不抓屏、不写剪贴板；没装 Snipaste 会给提示）。只画圈不点左键 = 回放右键。
  - **让路**：手势排除程序命中、前台是占满显示器的全屏程序、条目的触发条件不成立——这三种情况一律按「没命中」处理，回放右键。
- **滚轮快捷键**：把触发键写成 `WheelUp` / `WheelDown` 就能绑滚轮（一格 = 一次按下 + 抬起；高精度滚轮累积到 120 才算一格）。
- **角动作**：光标碰到屏幕四角触发（可设「停留毫秒」防误触）；同一角允许挂多条，层优先、条件优先。
- **边缘滚动**：光标贴到屏幕边缘时滚动滚轮触发；只旁听、不吞滚轮。
- 手势 / 角动作 / 边缘滚动都能设**归属层**与**触发条件**，动作就是同一套动作链。

### 触发条件（`when`）

同一条目可以按现场环境分流。条件不成立 = **这条不存在**（落到下一条同触发的条目；都没有就按正常输入处理）：

- 路径：存在 / 不存在 / 是文件 / 是目录 / 最近 N 分钟内被修改
- 变量：等于 / 不等于某值
- 前台：进程名（子串或通配）、窗口标题包含
- 设备：来自某台键盘 / 鼠标（可在设置里从「检测到的设备」下拉里选）

### 浮窗与消息

- **输入状态悬浮指示（HUD）**：显示当前层、按住中的修饰键等状态，可在设置里关。
- **快捷键提示框**：常显速查浮窗，显示你配置的快捷键清单；整块面板可拖动，光标进框自动穿透 + 变淡让位，停满 2 秒恢复。
- **触发提醒**：每次触发在右下角弹一条 3 秒气泡（动作名 + 触发键）。
- **消息页**：执行记录（时间线 / 流水线两种视图，含条件走向与并行成员）、命令结果、中止、失败、配置事件。有未读时托盘图标带红点。

### 配置：保存、备份、分享、同步

- **位置**（JSON，一个文件搞定）：Windows `%APPDATA%\com.kada\config.json`，macOS `~/Library/Application Support/com.kada/config.json`，Linux `~/.local/share/com.kada/config.json`。
- **落盘安全**：原子写（临时文件 → `fsync` → 重命名），同时留一份 `.bak`。解析失败绝不静默清空——先留档，能恢复就恢复，全失败才空配置 + 告警。
- **外部修改监听**：你在编辑器外改了配置文件，Kada 会检测到并提示；有未保存草稿时会先问你。
- **导入 / 导出**：导入必须选方式——**合并**（只增不删、不制造新冲突、设置保留本机）或**替换**（替换前自动存档一份）。
- **卡带**：把选中条目或整个目录导出成一个 JSON 卡带（仍是合法配置，对方走「导入 → 合并」就能吃下）；也可以在**卡带市场**里浏览、安装别人发布的卡带。
- **同步存档**：在设置里指定一个文件夹（网盘同步目录即可），之后每次保存都会写一份 `kada-config.json` 进去。
- **暂停**：托盘菜单或设置卡片一键暂停所有快捷键；编辑器里的「录入暂停」是限时租约（60 秒自动失效），避免边录边触发。

### 软件更新

- **检查**永远自动：启动后 8 秒首次检查，之后每 24 小时一次。
- **下载 / 安装**默认手动；打开「自动更新」后：发现即下载，并在电脑空闲较久时自动安装（便携版改为下次启动时安装，原位替换 `kada.exe` 后重启）。
- 更新包有 Ed25519 签名，版本号也签在包里；校验不过不会安装。
- 更新源可在设置里切换：ihomy 镜像（默认）/ GitHub Releases。

## 配置文件示例

```json
{
  "shortcuts": [
    {
      "name": "窗口居中",
      "triggers": ["Ctrl+Alt+C"],
      "actions": [{ "type": "app", "operation": { "op": "current_window", "action": "center" } }],
      "enabled": true
    }
  ],
  "remaps": [
    { "from": "CapsLock", "tap": "Escape", "hold": "Ctrl", "tap_timeout_ms": 200, "enabled": true },
    { "from": "RightCtrl", "lock_layer": "symbols", "enabled": true }
  ],
  "layers": [{ "id": "symbols", "name": "符号层", "mark": "#4f9cf9" }],
  "expansions": [
    { "trigger": ";mail", "replace": "hi@example.com", "enabled": true },
    { "trigger": ";day", "replace": "今天是 {date}", "enabled": true }
  ],
  "gestures": [
    { "pattern": "D,R", "actions": [{ "type": "keys", "keys": ["Ctrl+T"] }], "enabled": true }
  ],
  "settings": { "show_status_hud": true, "experimental": false }
}
```

## 常见问题

- **按键完全不触发**：先看「消息」页有没有配置告警；再确认没开「暂停所有快捷键」、当前程序不在「全局排除程序」里、前台不是全屏程序（开了「全屏程序里暂停」时）。
- **鼠标侧键不触发**：厂商软件（如 Logi Options+）可能把侧键从系统事件流里转走了，退出该软件再试。
- **手势让右键菜单变慢**：未命中时必然回放右键，菜单会晚十几毫秒；把常用程序加进「手势排除程序」即可完全不接管。
- **macOS 没反应**：辅助功能授权通常是关键；授权后一般要重启一次应用。
- **Linux 起不来 / 部分设备无反应**：看「消息」页给出的具体命令（`input` 组、udev 规则、`/dev/uinput` 权限）；触摸板与指点杆不被接管是刻意设计。
- **中文打不进去**：设置里把「文本注入」切到剪贴板模式（默认）；目标程序连粘贴都吞（游戏 / 终端）时两条通道都无效。
- **提示已有实例在运行**：Kada 只允许单实例（避免两套钩子互相打架），从托盘图标唤出已有窗口。

## 技术栈

- Rust workspace：`kada-core`（纯逻辑：键模型 / 解析匹配 / 配置模型 / 冲突检测 / 卡带摘取）+ `kada-hook`（平台输入层：全局监听 + 拦截 + 注入）+ `kada-actions`（动作执行引擎）
- 输入层：Windows `WH_KEYBOARD_LL` + `WH_MOUSE_LL`；Linux evdev + uinput；macOS `CGEventTap`
- Tauri 2 桌面壳（crate `kada`）+ Vite / TypeScript 前端（`kada-ui`）
- 四套主题：像素 CRT 深色 / 浅色、简约 深色 / 浅色（默认像素 CRT 深色），界面中英双语

## 构建与验证

```powershell
cargo test --workspace                     # 全 workspace 测试
cargo check -p kada                        # Tauri 壳（完整版）
cargo check -p kada --no-default-features  # 基础版（裁掉 automation：命令 / 脚本 / 条件 / 变量等）
npm --prefix ui run build                  # 前端构建（tsc + vite）
cargo run -p kada-hook --example demo      # 输入层冒烟 demo（三平台真人按键）
```

- 纯浏览器调试前端：`npm --prefix ui run dev` 后直开 `http://localhost:1420`（没有 Tauri 壳时自动注入模拟 IPC 与演示配置）。
- 打包：`npm run tauri -- build --bundles nsis`，需要 `TAURI_SIGNING_PRIVATE_KEY`（安装包签名必须带版本号，否则客户端拒装）；产物在仓库根 `target/release/bundle/`。**Linux 包**在 Windows 上打不出来，借 docker 容器出（`scripts/linux-package/`）；**macOS 包**由 CI 发布矩阵出。
